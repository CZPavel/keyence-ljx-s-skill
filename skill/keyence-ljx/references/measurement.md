# Measurement and programs

Resolve controller family and mode before selecting a tool. `measurement_tool_selection.yaml` is derived routing; the canonical tool record determines applicability and known outputs. Treat ROI, detailed parameter, and calculation fields marked unresolved as a targeted-corpus-fallback case. Program changes are state-changing; save and switch operations require verification.

For LJ-X8000 3D capture symptoms, resolve `acquisition` before changing a value. It carries documented paths for missing profiles, multiple reflections, blur, unstable light feedback, Dynamic Range, Exposure Time, Detection Sensitivity, Target Area, and light-intensity control.

For height-reference or curved-surface work, resolve `preprocessing`: Height Extraction and Zero Plane are separate from height-image filters. For numerous profile lines in a height image, resolve `measurement continuous-profile-measurement`; Scan Interval explicitly trades profile coverage against processing time. Profile Measurement may use a numeric range or a range that follows another profile's position/center-position result.
