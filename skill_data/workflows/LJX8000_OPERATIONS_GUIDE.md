Connect using documented Ethernet Non-Procedural settings.

## Software trigger

Issue a software trigger after the observable READY precheck.

## External trigger

Run external trigger through TRG/READY handshake.

## Read latest profile

## Fast profile read

Read latest 2D profile using PFRF.

## Switch program

Change active inspection program and verify read-back.

## Verify current program

Read active SD card/program.

## Acquire measurement result

Use configured result output only after measurement completion.

## External string correlation

Read externally specified string where configured.

## Reset and recovery

Recover with physical RESET or RS without treating them as equivalent.
